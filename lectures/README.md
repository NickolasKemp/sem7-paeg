# Матеріали ПАЕГ (Полторак В.П., 2026-27)

Джерело: [Google Drive](https://drive.google.com/drive/folders/11YCqRTwqDzwKG8eurmJVWrCap5k3f2mt).

- `original/` — файли як на диску (pdf, xlsx, docx, pptx).
- `text/` — витягнутий текст тих самих файлів (`<назва>.<ext>.txt`), для пошуку і читання агентами. xlsx-дампи містять клітинки у форматі `A1: =ФОРМУЛА  => значення`.
- Аудіо/відео записи лекцій не завантажені — посилання в `text/2 ПАЕГ a-v лекцій посилання.pdf.txt`.
