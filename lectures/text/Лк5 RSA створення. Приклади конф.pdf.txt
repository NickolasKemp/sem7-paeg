Розглянемо сам показник степеня

                           {(p-1)*(q-1)*J+1} .                     (6)
Він пов'язаний з числом Ейлера φ(s), наприклад, φ(8) = 4,
оскільки це є кількість цілих 0 < b < s, взаємно простих із s.
Тобто, таких b, для яких НСД(b, s) = 1. НСД – найбільший
спільний дільник. Шукаємо їх серед:

                             b = 1,2,3,4,5,6,7

Тут взаємно простими із s=8 є b=1, 3, 5, 7. Їх
всього φ(8) = 4.

Оскільки p та q прості, то:

- число Ейлера для p це φ(p) = (p-1);



- число Ейлера для q це φ(q) = (q-1).



Тому число Ейлера для n = p*q є наступне



                                   φ(n) = (p-1) (q-1) .            (7)

Звідси можна переписати відношення

 w^{ φ(n)*J+1} ≡ w mod n, w < n = p*q = pq . (8)



Якщо φ(n)*J+1, та J це деякі цілі числа, то

                                         зрівнюється


                    { φ(n)*J+1 } ≡ 1 mod φ(n) .                         (9)

Виникає питання: чи можемо ми подати цей
показник степеня (лівий вираз у (9)) у формі
добутку двох певних цілих чисел: e та d ?



Відповідь позитивна, ТАК! Лівий вираз із (9)
можна подати, як добуток двох цілих e та d.


                                    { φ(n)*J+1 } = e*d .          (10)



Вираз (10) можна подати у наступній формі

                             1 = e*d - φ(n)*J .                (10.А)

Показник { φ(n)*J+1 } є цілим числом.



Тому (10) та (10.А) можуть бути досягнуті
варіюванням цілого J,

або виконанням «розширеного алгоритма
Евкліда» для пошуку числа е, оберненого
мультиплікативно до числа d.



Оберемо випадково ціле 1< d < φ(n), але
взаємно просте із φ(n),                               НСД (d; φ(n)) = 1.



Відшукаємо е,наприклад, переборним
методом.

If { φ(n)*J+1 } = e*d

                 Then if { φ(n)*J+1 } ≡ 1 mod φ(n)

                 Then the product e*d is

                                         e*d ≡ 1 mod φ(n) .                (11)
