──────────────────────────────────────────────────────────────────────────────────────────────

  ▸ Один шар: символи шифруються окремо ключем A (e = 65537, n = 4097157919)
    cᵢ = ((mᵢ + cᵢ₊₁) mod n)^e mod n — кожен символ залежить від шифротексту символу праворуч
┌───┬────────┬──────┬────────────┬────────────┬──────────────────────────────┐
│ i │ Символ │ mᵢ   │ cᵢ₊₁       │ cᵢ         │ cᵢ у шифротексті (2 символи) │
├───┼────────┼──────┼────────────┼────────────┼──────────────────────────────┤
│ 1 │ О      │ 1054 │ 1246964997 │ 2231262100 │ 84fe 5b94                    │
│ 2 │ л      │ 1083 │ 1123945318 │ 1246964997 │ 4a53 2d05                    │
│ 3 │ е      │ 1077 │ 1022250938 │ 1123945318 │ 42fe 0b66                    │
│ 4 │ н      │ 1085 │ 2266918979 │ 1022250938 │ 3cee 4fba                    │
│ 5 │ а      │ 1072 │ 0          │ 2266918979 │ 871e 7043                    │
└───┴────────┴──────┴────────────┴────────────┴──────────────────────────────┘
    ✔ розшифрування закритим ключем A: «Олена»

  ▸ Навіщо зчеплення: два шифрування EVP || RP з різними RP
┌───────────────────┬────────────────────────────┬────────────────────────────┬──────────────────┐
│ Режим             │ RSA(EVP || RP₁)            │ RSA(EVP || RP₂)            │ Спільний префікс │
├───────────────────┼────────────────────────────┼────────────────────────────┼──────────────────┤
│ незалежні символи │ 74c7 623e 68b2 481c 0fc8 … │ 74c7 623e 68b2 481c 0fc8 … │ 28 з 36 символів │
│ зі зчепленням     │ 4c7b 7be0 0a07 7a48 36e5 … │ cd46 13e7 e387 9af4 81f4 … │ 0 з 36 символів  │
└───────────────────┴────────────────────────────┴────────────────────────────┴──────────────────┘
    ✘ без зчеплення RSA(EVP || RP) = RSA(EVP) || RSA(RP): будь-хто зашифрує ім’я кандидата відкритим ключем і впізнає голос
    ✔ зі зчепленням RP, дописаний у кінець, змінює кожен символ шару — однакові EVP стають непорівнюваними

  ▸ Багатошаровість: результат шару — вхідні дані наступного (порядок E → D → C → B → A)

    ✔ послідовне зняття шарів A → B → C → D → E повертає «Олена Петренко»
