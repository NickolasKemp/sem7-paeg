# Лабораторна робота №3 (ПАЕГ) — розподіл повноважень між БР та ВК

Програмна реалізація протоколу Е-голосування з розподілом повноважень: **бюро реєстрації (БР)** перевіряє
виборців і видає випадкові RN, **виборча комісія (ВК)** приймає та рахує бюлетені. 2 кандидати, 5 виборців,
RSA для шифрування та ЕЦП. Уся арифметика RSA, хеш квадратичної згортки та розширений алгоритм Евкліда
написані вручну (перенесено з ЛР1). У лекції 13 БР називається комісією реєстрації (КР).

## Запуск

```bash
npm start        # демонстрація протоколу: позитивні та негативні сценарії
npm test         # 25 модульних тестів (node:test)
npm run typecheck
```

Перегенерація матеріалів звіту:

```bash
npm run shots    # скріншоти виконання → assets/*.png
npm run report   # звіт → report/Звіт_ЛР3_ПАЕГ.docx і .pdf
```

Потрібен Node.js ≥ 22.6 (TypeScript виконується напряму, без збірки).

## Структура

| Файл | Призначення |
| --- | --- |
| `src/bigint-math.ts` | `modPow`, розширений алгоритм Евкліда, `modInverse`, Міллер — Рабін, генерація простих |
| `src/rsa.ts` | пара ключів, блокове шифрування, хеш `Hᵢ = (Hᵢ₋₁ + Mᵢ)² mod n`, ЕЦП |
| `src/types.ts` | звернення до БР, список RN, повідомлення (ID; RN; бюлетень), причини відмов, серіалізація |
| `src/bureau.ts` | БР: реєстр громадян, перевірки, видача RN, реєстр «виборець — RN — ключ», підписаний список RN |
| `src/commission.ts` | ВК: прийняття списку RN, розшифрування, перевірки, позначення RN, підрахунок, публікація |
| `src/voter.ts` | виборець: власні ключі, ID, підписання + шифрування повідомлення, перевірка свого голосу |
| `src/main.ts` | сценарій демонстрації |
| `tools/` | скріншоти терміналу (ANSI → HTML → PNG) і генерація звіту |

Дані БР і ВК — приватні поля (`#…`); модулі не мають посилань один на одного, список RN передається
серіалізованим текстом з ЕЦП БР. До ВК від виборця надходить лише шифротекст, без імені.

## Перевірені сценарії

Реєстрація: `ALREADY_REGISTERED` (другий RN), `NOT_IN_ROLL`, `IDENTITY_MISMATCH` (чужий паспорт), `NO_VOTING_RIGHT` (< 18 р.).
Передача списку: підроблений і змінений список RN відхиляються за ЕЦП БР.
Голосування: `UNKNOWN_RN`, `RN_USED`, `DUPLICATE_ID`, `BAD_SIGNATURE` (викрадений RN; підміна після підписання),
`INVALID_BALLOT`, `UNDECRYPTABLE`. Перевірка виборцем: чесна публікація підтверджується, підміна та вилучення бюлетеня
виявляються. Аналіз: БР за RN в опублікованих підписаних бюлетенях деанонімізує голоси.

## Відхилення від лекції

- Список RN підписується ЕЦП БР (лекція 13: «всі повідомлення мають бути зашифровані і підписані»).
- БР перемішує список RN, ВК публікує бюлетені впорядкованими за ID — порядок не відтворює реєстрацію/голосування.
- Право голосу моделюється віком ≥ 18 на день виборів.

## Матеріали

- `report/Звіт_ЛР3_ПАЕГ.docx` — звіт (Times New Roman 14, інтервал 1.5, абзац 1.25, по ширині); `.pdf` — та сама версія для перегляду.
- `assets/` — скріншоти виконання (рисунки звіту) та повний текстовий вивід демонстрації.
