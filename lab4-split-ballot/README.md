# Лабораторна робота №4 (ПАЕГ) — розподіл бюлетеня між ВК-1 та ВК-2

Програмна реалізація протоколу Е-голосування з розділенням бюлетеня: **2 кандидати, 5 виборців**,
три незалежні органи — ЦВК, ВК-1, ВК-2. ID кандидата ділиться на два множники, кожен шифрується
відкритим ключем ЦВК (RSA) і надсилається своїй ВК з ЕЦП виборця. ЦВК спочатку перемножує
шифротексти (мультиплікативна гомоморфність RSA), потім розшифровує. Уся арифметика RSA, хеш
квадратичної згортки та ЕЦП написані вручну, без криптобібліотек.

## Запуск

```bash
npm start        # демонстрація: гомоморфність, протокол, негативні сценарії, атаки комісій
npm test         # 16 модульних тестів (node:test)
npm run typecheck
npm run shots    # скріншоти виконання → assets/*.png
npm run report   # звіт → report/Звіт_ЛР4_ПАЕГ.docx і .pdf
```

Потрібен Node.js ≥ 22.6 (TypeScript виконується напряму, без збірки).

## Структура

| Файл | Призначення |
| --- | --- |
| `src/bigint-math.ts` | `modPow`, розширений алгоритм Евкліда, `modInverse`, Міллер — Рабін, генерація простих |
| `src/rsa.ts` | ключі, `encrypt`/`decrypt` числа, `multiplyCiphers`, хеш, ЕЦП |
| `src/split.ts` | розклади ID на множники, відбір розкладів, що не видають вибір |
| `src/types.ts` | повідомлення `EDS(RSA(EVP), ID)`, публікації, причини відхилення |
| `src/voter.ts` | виборець; перевірки публікацій ВК і ЦВК за квитанцією |
| `src/central-commission.ts` | ЦВК: ID кандидатів (24, 36), список виборців, ключі, об'єднання → розшифрування, підрахунок |
| `src/part-commission.ts` | ВК-1 / ВК-2: список від ЦВК, перевірки, публікація частин |
| `src/attacks.ts` | підбір множника перебором (RSA без доповнень детермінований) |
| `src/main.ts` | сценарій демонстрації |

## Сценарії

Позитивні: таблиця гомоморфності з методички (ключі (7, 33)/(3, 33)); 5 бюлетенів, підсумок 3:2;
виборці підтверджують публікації ВК-1, ВК-2 і ЦВК.

Негативні: `NOT_IN_LIST`, `BAD_SIGNATURE` (підміна частини, чужий ключ), `ALREADY_VOTED`;
ВК-1 підміняє множник 12 → 18 (один бюлетень стає 36, інший — 54 → `NOT_A_CANDIDATE`);
ВК-2 не публікує частину (`MISSING_PART`); змова ВК-1 і ВК-2; нечесна ЦВК — усе виявляють виборці.
