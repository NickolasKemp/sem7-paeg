▌ Сценарій G. Змова БР і ЦВК: зіставлення записів реєстрації з ID виборців у результатах
──────────────────────────────────────────────────────────────────────────────────────────────
┌─────────────────────────────┬────────────────┬──────────────────────────────────────────┐
│ Запис БР: ПІБ               │ H' (бачила БР) │ Збіг з H(мандат) будь-кого в результатах │
├─────────────────────────────┼────────────────┼──────────────────────────────────────────┤
│ Коваленко Андрій Сергійович │ 0x209f32…ed0b  │ немає                                    │
│ Шевченко Олена Миколаївна   │ 0x8759ed…bc1f  │ немає                                    │
│ Бондаренко Богдан Юрійович  │ 0x248526…8e8f  │ немає                                    │
│ Ткаченко Марія Василівна    │ 0x57bf21…b57b  │ немає                                    │
└─────────────────────────────┴────────────────┴──────────────────────────────────────────┘
    · для будь-якої пари (H', H) існує r: H' = H · rᵉ mod n — будь-яке зіставлення однаково ймовірне
    · зв'язок «особа — мандат» знає лише виборець, який зберігає r
